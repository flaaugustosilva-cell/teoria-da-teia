# Conjectura C2 (paridade no centro da janela)

Data: 20/11/2026. Esta conjectura foi registrada **depois** de ver os dados que a inspiraram. Esses dados, portanto, **não** a confirmam.

## Enunciado

Na população oficial (teias de altura ≥ 3 incorporáveis em Minkowski 3+1, com peso 1/|Aut|), para todo n ≥ 6,

  W_ímpar > W_par,

em que W_par e W_ímpar são as somas de 1/|Aut| sobre as classes com B par e com B ímpar, respectivamente.

## Forma equivalente

Como e^{iπB} = (−1)^B e B = n − N₀ + 9N₁ − 16N₂ + 8N₃ inclui o termo n, temos

  𝒵_boa(π) = W_par − W_ímpar.

Então C2 diz que **𝒵_boa(π) < 0** para n ≥ 6, na convenção de fase usada em todo o repositório (fase e^{iθB}, com θ = 2β).

## Situação da evidência

- **Dados que inspiraram a conjectura** (exploração, `EXPLORATORIO_ESTRUTURA_FINA.md`): na população oficial, W_par − W_ímpar vale −14,25, −3,52, −54,10, −76,90 e −687,47 para n = 6 a 10. Esses números **não** contam como teste.
- **n = 5 é exceção:** +1,42. Por isso o enunciado começa em n = 6. Essa fronteira também foi escolhida depois de ver os dados.
- **n = 11 auxiliar:** −1014,39, na população de todas as ordens de altura ≥ 3. Essa é **outra população**, não a oficial, e o resultado **não** é confirmação independente de C2.
- **Observação exploratória:** quem carrega o sinal são as teias conexas. As desconexas têm sinal oposto a partir de n = 7.

## Como C2 pode ser testada

- **Teste independente:** n ≥ 12 na população oficial, que exige certificar a incorporabilidade, ou o n = 11 oficial, que está adiado.
- **Demonstração** para todo n ≥ 6.

Até lá, C2 é uma conjectura, sem teste.
